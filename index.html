Обучение

Три приложения для самостоятельной учёбы. Прогресс хранится на устройстве. Уроки доступны после загрузки; для новых аудио и первого запуска Python нужен интернет.

АнглийскийА1–А2: подробные уроки, ежедневное повторение, разговорная практика и переводчик
Курс: техника и ИИ16 уроков, проверка кода на разных данных и три практических проекта
Книга дня30 книг, пять подробных аудиоразборов, задачи и дневник применения
Как поставить на iPhone
  1. Откройте нужное приложение в Safari.
  2. Нажмите «Поделиться» (квадрат со стрелкой вверх).
  3. Выберите «На экран Домой» и нажмите «Добавить».

Повторите для остальных приложений: у каждого своя иконка.
